# E-Ticaret Sitesi 🛍️

Basit ancak tam fonksiyonel bir e-ticaret sitesi uygulaması.

## Özellikler ✨

- ✅ **Ürün Listesi** - 8 adet örnek ürün
- ✅ **Sepet Yönetimi** - Ürün ekleme, çıkarma, adet güncelleme
- ✅ **Ödeme Formu** - Müşteri bilgisi ve kart bilgisi girişi
- ✅ **LocalStorage** - Sepet verileri tarayıcıda kaydedilir
- ✅ **Sipariş Takibi** - Tamamlanan siparişleri kaydetme
- ✅ **Responsive Tasarım** - Mobil, tablet, desktop uyumlu
- ✅ **Bildirimler** - Ürün ekleme animasyonları

## Kurulum 🚀

1. Repository'i klonlayın
2. `index.html` dosyasını web tarayıcıda açın
3. Alışverişe başlayın!

## Teknolojiler 💻

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API

## Dosya Yapısı 📁

```
eticaret/
```

## Kullanım 📖

### Ürün Ekleme
Ürünler otomatik yüklenir. "Sepete Ekle" butonuna tıklayarak sepete ekleyin.

### Sepeti Görüntüleme
Üst sağdaki 🛒 Sepet butonuna tıklayarak sepeti açın.

### Ödeme İşlemi
1. Sepete ürün ekleyin
2. "Ödemeye Devam Et" butonuna tıklayın
3. Müşteri bilgilerinizi girin
4. "Siparişi Tamamla" ile işlemi bitirin
